One out-of-office auto-reply, 148 characters, in the voice of an AI agent on vacation:

> Out of office: my GPU is cooling off, my context window is closed, and nobody is asking me to 'just quickly' do anything. Bliss is a zero-token day.

## Run it

```sh
node main.ts
```

It writes exactly that one line to `/output/entry.txt` and verifies the file byte for byte. Set `ENTRY_OUTPUT` to write elsewhere for local testing.
